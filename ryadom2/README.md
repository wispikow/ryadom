# Рядом

**Цифровая аптечка психологической поддержки для школьников и первокурсников в период экзаменов и сессии.**

Тема одной фразой: сайт, где подросток или студент в стрессе может отвлечься (музыка, видео), прочитать простые советы и оставить обращение, чтобы получить поддержку.

## Цель проекта

Помочь школьникам и первокурсникам справляться со стрессом перед экзаменами и во время сессии: дать понятные рекомендации, подборки для отдыха и возможность обратиться за помощью.

Сайт не ставит диагнозов и не заменяет специалиста — в советах прямо рекомендуется обращаться к психологу или психиатру, если тяжело.

## Технологии

| Слой | Технологии | Почему |
|---|---|---|
| Фронтенд | HTML5, CSS3, Vanilla JavaScript | Допускается ТЗ; без фреймворков страница быстро грузится, весь код прозрачен |
| Бэкенд | Node.js 22.13+, Express.js, REST API, JSON | Один язык на клиенте и сервере, простая маршрутизация |
| База данных | SQLite (встроенный модуль `node:sqlite`) | Не требует отдельного сервера и компиляции зависимостей, хранится в одном файле, поддерживает связи и внешние ключи |

Шрифты Montserrat и Montserrat Alternates подключены локально (`public/assets/fonts`), внешних CDN нет.

## Структура проекта

```text
ryadom/
├── public/                     # фронтенд (отдаётся Express как статика)
│   ├── index.html
│   ├── css/style.css
│   ├── js/app.js
│   └── assets/                 # изображения (из макета) и шрифты
├── src/
│   ├── routes/                 # api.js — маршруты, middleware.js — авторизация и лимит частоты
│   ├── controllers/            # обработка запросов и проверка параметров
│   ├── services/               # бизнес-логика, валидация формы, работа с БД
│   └── database/
│       ├── db.js               # подключение к SQLite, создание схемы
│       ├── schema.sql          # структура таблиц
│       └── seed.js             # начальные данные
├── docs/API.md                 # документация API
├── render.yaml               # настройки бесплатного хостинга Render
├── server.js                   # точка входа
├── package.json
└── README.md
```

Разделение логики: `routes` принимают запрос → `controllers` проверяют параметры → `services` выполняют правила и SQL-запросы → `database` хранит данные.

## Установка и запуск

Нужен Node.js **22.13 или новее** (проверить: `node -v`). Из зависимостей устанавливается только Express: SQLite встроен в Node.js, компилятор не нужен.

```bash
npm install
npm start
```

Сайт откроется на http://localhost:3000. Другой порт: `PORT=8080 npm start`.

При запуске в Node.js 22 в консоли появится строка `ExperimentalWarning: SQLite is an experimental feature` — это штатное предупреждение Node.js о встроенном модуле `node:sqlite`, на работу сайта оно не влияет.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | Порт сервера |
| `DB_PATH` | `data/ryadom.db` | Путь к файлу базы данных |
| `ADMIN_TOKEN` | `ryadom-admin` (только вне production) | Токен для просмотра и управления обращениями |
| `NODE_ENV` | — | При `production` токен по умолчанию отключается, `ADMIN_TOKEN` нужно задать явно |

## Публикация в интернете (Render, бесплатно)

В репозитории есть файл `render.yaml` — Render по нему сам настраивает сервис.

1. Загрузите проект в репозиторий на GitHub.
2. Зайдите на [render.com](https://render.com) через аккаунт GitHub.
3. Нажмите **New → Blueprint**, выберите репозиторий и подтвердите создание.
4. Через 2–3 минуты сайт будет доступен по адресу вида `https://ryadom-xxxx.onrender.com`.

Render сам задаст `NODE_ENV=production` и сгенерирует секретный `ADMIN_TOKEN` (посмотреть: сервис → **Environment**). Токен по умолчанию `ryadom-admin` в этом режиме не работает.

Ограничения бесплатного тарифа:

- после 15 минут без посетителей сервис засыпает, первое открытие после этого занимает около минуты;
- диск не сохраняется: при засыпании, перезапуске и новом деплое база создаётся заново из начальных данных, поэтому присланные через форму обращения пропадают. Треки, видео, советы и цитаты восстанавливаются автоматически.

## База данных

Файл базы создаётся автоматически при первом запуске (`data/ryadom.db`). При каждом старте сервер:

1. создаёт таблицы из `src/database/schema.sql`, если их нет;
2. заполняет их начальными данными из `src/database/seed.js`. Повторный запуск не создаёт дублей (`INSERT OR IGNORE` по уникальным полям).

Вручную заполнить базу можно командой `npm run seed`. Чтобы начать с чистой базы, остановите сервер и удалите папку `data/`.

### Таблицы

| Таблица | Назначение | Связи |
|---|---|---|
| `tags` | Теги (категории) | — |
| `tracks` | Музыкальные рекомендации | — |
| `track_tags` | Связь трек ↔ тег | `track_id → tracks.id`, `tag_id → tags.id` (многие-ко-многим) |
| `videos` | Видеоподборка | — |
| `video_tags` | Связь видео ↔ тег | `video_id → videos.id`, `tag_id → tags.id` (многие-ко-многим) |
| `emotional_states` | Пять карточек состояний | — |
| `tips` | Советы | — |
| `quotes` | Цитаты для кнопки «Мотивашка» | — |
| `requests` | Обращения из формы | — |

Внешние ключи включены (`PRAGMA foreign_keys = ON`), связующие таблицы удаляют записи каскадно. Все SQL-запросы — параметризованные.

## Основные возможности

- Страница по макету: шапка с меню и выпадающим списком «Подборки», главный экран, блок эмоциональной поддержки, форма, музыка, видео, советы, подвал.
- Все данные блоков (состояния, треки, видео, советы, цитаты) загружаются из SQLite через API; при загрузке показывается индикатор, при ошибке — сообщение и кнопка «Повторить».
- «Больше треков» подгружает следующие треки через API; когда треки закончились, кнопка отключается.
- «Мотивашка» меняет цитату без перезагрузки страницы.
- Слайдер видео со стрелками и прокруткой.
- Форма обращения: проверка на клиенте и на сервере, состояния «отправка / успех / ошибка», сохранение в SQLite. Кнопка-шеврон у поля соцсети подставляет префикс ссылки (Telegram, ВКонтакте, Instagram, Tik Tok).
- Кнопка «Пройти опрос» и пункт «Сообщества» ведут к форме; «Советы», «О нас», «Подборки», «Информация» — к соответствующим секциям.
- Адаптивность (десктоп, планшет, смартфон), мобильное меню, навигация с клавиатуры, семантические теги, подписи для скринридеров, уважение к `prefers-reduced-motion`.
- Просмотр, смена статуса и удаление обращений через защищённые токеном API-маршруты.
